## C2.1 — SIGINT during `ocm install big-03@ocm-e2e3-collide --force` displacing a hand-written file

Setup: home-c1-03, `ocm add --explicit` MP-F (nothing auto-installed), then a
hand-written user file at the component target
`$H/.config/opencode/commands/big-03:clash.md`:

```
# my own clash command
hand-written by the user
```

Baseline (no interrupt):

```
$ env HOME=$H ocm install big-03@ocm-e2e3-collide --force
exit=0
--stdout--
installed big-03@ocm-e2e3-collide (1 command)
restart opencode to activate
--stderr--
  warning: displaced your commands/big-03:clash.md → /tmp/ocm-e2e3/home-c1-03/.cache/ocm/displaced/2026-09-15T17-16-59-523Z/tmp/ocm-e2e3/home-c1-03/.config/opencode/commands/big-03:clash.md
```

On disk: dest is now a symlink into the clone; the user's file sits at
`displaced/<ts>/<abs-original-path>`; `displaced-records.json` has one record
{marketplace: ocm-e2e3-collide, plugin: big-03, dest, dir}. Baseline
recoverability: `ocm uninstall big-03@ocm-e2e3-collide` prints
`restored your commands/big-03:clash.md (was displaced by big-03)` and the
file returns byte-identical (stdout, exit 0). Baseline is exactly spec 21.

Prompt-time Ctrl+C control (spec 16 path, home-c1-03t, `ocm add` MP-B):
`^C` echoed, then `interrupted — marketplace "ocm-e2e3-exec" is added and
materialized / trust: undecided (executable components are blocked) / run
ocm trust ocm-e2e3-exec to decide, or ocm remove ocm-e2e3-exec to undo`,
exit 130. Correct.

Timing: the whole install takes ~30 ms. Note: `kill -INT` on shell
background jobs is ignored (POSIX async-list SIG_IGN), so all interrupts were
delivered through an expect pty (`send "\x03"`), which provably delivers
SIGINT (the control above).

Sweep 1 (delays 0–50 ms, 1–2 ms steps, fresh state per attempt — hand file
restored, displaced/ and records removed, registry flipped back to
not-installed): 36/36 attempts OK — killed-before-write (dest still the
user's file) or completed (dest symlink + displaced copy + record). Registry
valid JSON after every attempt.

Sweep 2 (critical band 13–17 ms × 10 rounds, 40 runs): 39/40 OK, 1 LOST:

```
delay=14 sigint-delivered=yes dest=missing displacedCopy=yes record=no -> LOST
```

Hunted to a frozen repro (2nd occurrence, attempt 8 × delay 14 ms). State:

- `$H/.config/opencode/commands/big-03:clash.md` — **gone** (no file, no symlink)
- `$H/.cache/ocm/displaced/2026-09-15T17-19-30-104Z/…/commands/big-03:clash.md`
  — present, sha `fdcf681d…` = the user's hand-written content
- `$H/.cache/ocm/displaced-records.json` — **0 bytes** (first repro: absent;
  this repro: truncated mid-write — the record write is a bare
  `writeFileSync`, not atomic, so an interrupt can also wipe any previously
  recorded displacements)
- registry: big-03 enabled, installedAt set, valid JSON

So the SIGINT landed between `renameSync(dest → displaced/…)` (loader/links.js
takeOver) and the `appendDisplacement` record write / symlink creation.
