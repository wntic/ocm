## A1.7 — F58: `--trust` is not blind (H=home-a1-06, home-a1-06b)

```
$ env HOME=$H ocm add file:///tmp/ocm-e2e3/repos/exec-src --trust </dev/null
exit=0
--stdout--
cloning file:///tmp/ocm-e2e3/repos/exec-src...
installed auto-sync loader (…)
marketplace "ocm-e2e3-exec" ships code that opencode will execute:
  mcp     notify/everything (local server: )
  plugin  notify/notify (plugins/notify/plugin/notify.js)
this code runs with your shell's permissions on every opencode start.
review it at /tmp/ocm-e2e3/home-a1-06/.cache/ocm/marketplaces/ocm-e2e3-exec
added marketplace "ocm-e2e3-exec"
  notify (1 plugins, 1 mcp servers)
…
--stderr--
```

The full listing prints **before** the grant (registry `trust.code: "granted"`,
`ocm--notify--notify.js` + `ocm--notify--everything` linked after). Order ✓.
JS plugin line has type + plugin + path ✓. MCP line has type + plugin but the
command line is **empty**: `(local server: )` even though mcp.json says
`{"command": "node", "args": ["-e", "console.log('everything mcp placeholder')"]}`.

Root cause (read-only inspection, src/commands/trust-prompt.ts:16): the detail
is `Array.isArray(value?.command) ? value.command.join(" ") : ""` — a string
`command` (the standard MCP shape, and what opencode.json itself stores) falls
through to `""`. Probe with an array-shaped command + a remote server in my
own copy (commit b2ba162, home-a1-06b):

```
  mcp     notify/everything (local server: node -e console.log('everything mcp placeholder'))
  mcp     notify/remote-srv (remote server: https://example.test/sse)
```

So array commands and remote URLs render; string `command` + `args` renders
empty. Also no path is shown for MCP components (JS shows rel path; MCP shows
only `plugin/name`) — the mcp.json location is implied by "review it at <dir>".

**Verdict A1.7 / F58: PARTIAL — still open (narrowed).** The listing exists,
precedes the grant, and covers type/plugin/path-for-JS; but for the standard
string-command MCP shape the command line is blank, so the user trusts an MCP
server blind. See finding A1-D2.
