Expected:    refused with an error naming the reason: the path escapes the plugin directory (spec 15 §4: "`relativePath` already refuses `../`")

Impact:      an author reading this checks whether the file is valid JSON, finds that it is, and is stuck; the real rule — plugin-relative containment, `../` refused — is never named
Root cause:  loader/manifest.js:128 — the escape (`relativePath` → null) and the missing-file cases share one message
Status:      new
